# Widgets Layer

Widgets are large UI blocks composed of multiple entities and features.

A widget represents a meaningful section of a page.

## Examples

- Header
- Footer
- Sidebar
- Topic Grid
- Question List
- Search Panel

## Responsibilities

- Compose entities
- Compose features
- Build reusable page sections

## Rules

Widgets should not contain routing logic.

Widgets should remain reusable across multiple pages whenever possible.
